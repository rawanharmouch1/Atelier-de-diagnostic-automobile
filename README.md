\# Atelier de Diagnostic Automobile 

WordPress website for an automotive workshop.

## How to run 

1. Clone the repository.
2. Create a local WordPress site.
3. Copy the project files into the WordPress public folders.
4. Create a MySQL database.
5. Import the project database.
6. Update wp-config.php with your local database information.
7. Start the local server and open the website in the browser.
